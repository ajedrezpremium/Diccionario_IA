## En qué consiste

Para enseñar a un modelo a distinguir una reclamación de una consulta, necesitas ejemplos ya clasificados. Ese es el etiquetado. Cuanto más claro sea el criterio y más consistente la etiqueta, mejor aprenderá.

El problema típico es el desacuerdo: dos personas etiquetan lo mismo de forma distinta. Se resuelve con una guía, ejemplos de referencia y revisiones cruzadas. Sin acuerdo, el modelo aprende ruido.

## Una analogía para entenderlo

> Corregir exámenes con una plantilla común. Si cada profesor aplica un criterio, las notas no son comparables.

## Ejemplo real de negocio

Una tienda etiqueta 2.000 reseñas como positiva, neutra o negativa. Antes de empezar, define qué hacer con las mixtas y revisa una muestra para medir el acuerdo.

## Cómo aplicarlo en tu pyme

Si externalizas el etiquetado, exige guía, control de calidad y una muestra revisada por tu equipo. La etiqueta es criterio de negocio, no solo una tarea mecánica.

## Errores frecuentes

No definir los casos límite, medir solo velocidad o usar etiquetas que nadie revisa.
