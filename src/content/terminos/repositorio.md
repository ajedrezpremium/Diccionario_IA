## En qué consiste

Un repositorio guarda algo más que archivos: guarda la historia. Cada cambio queda registrado con autor, fecha y motivo. Si algo se rompe, puedes comparar, revertir o recuperar una versión anterior.

GitHub, GitLab o Bitbucket añaden colaboración, revisión de cambios y automatizaciones. Para una web como esta, el repositorio es también el origen del despliegue: cada push puede publicar una nueva versión.

## Una analogía para entenderlo

> El cuaderno de actas de una obra, con cada plano fechado y firmado. Siempre puedes saber quién cambió qué.

## Ejemplo real de negocio

El Diccionario IA vive en un repositorio de GitHub. Cada ficha nueva es un cambio revisable y Vercel publica automáticamente la versión aprobada.

## Cómo aplicarlo en tu pyme

Si encargas una web o un agente, pide que el código esté en un repositorio tuyo o accesible. Es tu seguro ante abandonos y cambios de proveedor.

## Errores frecuentes

Subir claves y datos personales, trabajar sin ramas ni revisiones o no tener copia fuera del ordenador de una persona.
